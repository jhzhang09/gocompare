# 原生界面设计规范

GoCompare 采用参考 `godiff` 的现代专业对比工作台视觉与交互体系，基于 MyGo Native UI 构建，兼顾高效对比体验与原生质感。

## 视觉原则

- **高呼吸感与精致对齐**：使用左右对称双源结构、居中微交互胶囊栏、清晰的目录树与面包屑导航，告别传统工具生硬的厚重色块。
- **Theme-First 双主题调色板**：全面适配浅色与暗色模式，卡片与面板使用分层背景与半透明发丝线描边（Hairline Border），避免生硬的纯黑纯白或刺眼的高对比反差。
- **语义化强调色**：
  - 左侧来源（Left）：柔和青绿（`#10b981`），用于标识左侧标识与增量。
  - 右侧来源（Right）：优雅海蓝（`#3b82f6`），用于标识右侧标识与增量。
  - 差异强调（Modified）：琥珀橙（`#f59e0b`），用于标识内容变更。
  - 冲突危险（Conflict）：珊瑚红（`#ef4444`），用于标识合并冲突与关键警告。
- **圆角胶囊与微卡片（Pill & Chip）**：状态标签、文件差异状态使用 12px 圆角胶囊，内置等宽或精细字体与弱饱和同色系发丝边框。
- **矢量化图形与图标**：使用内联矢量 SVG 作为主图标来源，禁止 Emoji 占位或跨平台失真的文字符号。

## 布局体系

1. **左侧 macOS 风格原生侧边栏**：
   - 随系统深浅主题自适应浅灰/石墨黑微底色。
   - 分组微标区（`WORKSPACES` / `COMPARISONS`），分类层级清晰。
   - 激活菜单项采用浮起微卡片设计（浅色底纯白卡片加柔和微阴影，深色底炭灰浮层），告别大色块包裹。
2. **顶栏与双源路径栏**：
   - 双路径统一收纳在居中对称的胶囊面板中，中间嵌入圆角微交互 Swap 按钮。
   - 按钮尺寸精细，具备平滑悬停与点击反馈。
3. **对比窗格与面包屑头部**：
   - 窗格头部采用路径面包屑布局：父级目录使用弱化文本显示（`parent/`），文件名加粗高亮，直观辨识。
   - 左侧保留 `LEFT` / `RIGHT` 微徽标，右侧平铺保存、另存为等快捷动作，锁定不可换行与变形。
4. **状态栏与底部信息**：
   - 底部紧凑状态条展示当前编码、换行符（CRLF/LF）、差异块统计与比对耗时。

## 响应式与跨平台要求

- 核心操作工具栏与双源输入在 900px（紧凑型窄视口）和 1380px（标准宽屏）下均严格通过不重叠、不截断测试。
- 文本渲染跟随系统原生字体渲染管线，对比代码区域固定等宽字体。
