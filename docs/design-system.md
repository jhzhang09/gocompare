# 原生界面设计规范

方向：高信息密度的比较工作台；使用左右来源及中间差异操作建立识别。所有界面通过 MyGo Native UI 构建。

- 顶部产品栏、对称路径栏、上下文工具栏、内容区、保存状态栏。
- 比较页共享行对齐；编辑状态及未保存标记必须清晰。
- 界面字体跟随系统，内容等宽；间距以 4／8／12／16 为基础。
- 主操作蓝色 `#265DAB`，左侧青绿 `#176B5B`，右侧紫色 `#8054A3`；内容采用系统深浅主题。
- 差异不能只靠颜色说明，同时提供行号、方向和文本状态。
- 应用 SVG 为图标唯一来源；`go run ./tools/genicon` 通过 MyGo 渲染 PNG。
- 键盘焦点、自动换行、中文输入法、屏幕阅读器纳入验收。

当前落地基础工作区、顶栏中的应用图标和 MyGo 版本、同屏双侧编辑、合并页的三栏对齐、图片比较画布、只读的媒体标签、版本与注册表的文件结果，以及目录比较的过滤、权限、时间和链接控件。紧凑密度、概览条、对比度验收和设计精修尚未完成。

## 文件／目录工作区修订

采用固定 154 DIP 深蓝导航、紧凑标题栏和左右对称来源区。浅深主题的内容背景沿用系统，蓝色只表示主要操作，绿色／紫色区分单侧来源，琥珀色表示差异。目录以共享行展示双方名称与大小，缺失侧留空；目录层级用缩进和展开标识表达，避免整行居中巨型按钮。保存动作放在对应文件标题内，高级对齐与规则收在比较选项中。

核心按钮在 900 和 1380 像素窗口检查；框架版本保留在 CLI 帮助与构建信息，不占据日常工作区。UI 测试通过控件标识定位编辑器，不再用旧坐标模拟点击。
