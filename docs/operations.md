# 本地目录操作契约

日期：2026-10-31。实现位置：internal/compare、internal/operations、internal/native/directory.go。

## 比较与计划

目录按原始相对路径配对，递归扫描，不跟随符号链接。相同、不同、单侧、类型变化和读取错误分别表示。子项差异向父目录汇总，错误不会显示为相同。当前按内容比较文件，不提供所有属性和过滤规则，扫描尚非渐进展示。

支持向左／向右更新、双向更新、向左／向右镜像。更新只复制较新的不同内容及单侧来源；双向更新不传播删除，不能称为基于历史的双向同步。时间戳相同但内容不同时报告冲突，用户可检查后选择镜像规则。类型冲突和需要复制的链接暂时拒绝规划。

预览自身只读，记录源／目标的 SHA-256、大小、时间和权限。根目录先规范化到实际路径；同一目录、互为祖先的目录不允许同步。

## 执行

GUI 需要先预览再确认。CLI 需要 `--apply` 并显式提供备份目录。备份目录必须在两侧根目录之外。

执行前核对所有前置条件，各项执行前再核对，路径组成部分不得是符号链接。先创建父目录、再复制、最后删除文件和空目录，删除目录按子项优先。文件覆盖和删除之前备份；复制通过同目录临时文件发布，保留来源文件的权限与修改时间。新文件采用不覆盖链接发布，不支持硬链接的文件系统会报告错误。

每项操作前保存 pending，成功后写入 completed。日志和备份放在备份目录下的 `sync` 子目录，同一备份目录只能开始一次执行。失败和取消会停止后续操作并回滚已完成项。日志持久化失败会明确报告，不伪装成未发生变更。`ExecutePauseBefore` 在指定动作前暂停且不回滚，`Resume` 继续同一份日志。

## 尚未提供的保证

- 没有跨进程原子比较并交换；检查与发布之间仍有竞争窗口。
- 执行失败会回滚已完成操作。崩溃后的未完成日志不会自动重放，应检查 pending 与目标实际内容。
- 不保证目录 fsync、NTFS ACL、扩展属性、硬链接关系或源目录权限保留。
- 暂不处理类型冲突、链接复制、把远程来源接进目录同步、回收站和完整过滤策略。暂停后续传已经由同一日志上的 Resume 覆盖。
- 备份目前不自动清理，防止静默删除恢复数据；保留策略尚待实现。

这些边界保留在功能矩阵中，不能凭本地常规路径通过就标记同步功能完整完成。
