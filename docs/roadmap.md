# 开发阶段与验收

完整功能对齐是最终目标，各阶段是实施顺序。2026-10-31 已建立首个可运行版本，P0、P1 均尚未完整完成。

| 阶段 | 工作 | 通过条件 |
|---|---|---|
| P0 | 原生比较组件验证 | 同屏双侧编辑、多栏对齐、输入法、后台重算，以及 HTML／打印路线都有运行证据 |
| P1 | 工程、品牌、工作区 | GoCompare 命名和结构、主题、语言、会话恢复、三平台启动 |
| P2 | 文本比较闭环 | 编码、规则、算法、对齐、编辑、保存、补丁矩阵通过 |
| P3 | 目录和同步 | 扫描、配对、过滤、操作预览、执行与失败恢复通过 |
| P4 | 合并 | 三方文本、输出编辑、目录合并及冲突恢复通过 |
| P5 | 专用类型 | 表格、Hex、图片、媒体、PE 和转换器逐格式通过 |
| P6 | 扩展来源 | 各远程／云／压缩包／快照／SVN 能力逐项通过 |
| P7 | 系统和自动化 | Windows 专项、Shell、CLI、脚本、报告、打印与兼容层通过 |
| P8 | 发布 | 旧链路清理、文档、签名、安装升级、性能与完整功能矩阵通过 |

## 紧接当前实现的工作

1. 已通过受控 MyGo 补丁实现同屏双侧编辑，接着验证多栏对齐、真实 IME 和手工锚点；禁止复制整个编辑器作为应用私有分叉。
2. 把差异计算改为可取消、带输入版本的后台结果，建立超长行与重复内容基准。
3. 增加 Save As、自动备份、平台替换语义和元数据保留。
4. 引入版本化会话、语言切换和工作区恢复。
5. 建立目录条目模型与渐进扫描，再实现操作计划。

每项完成时更新 feature-parity.md，记录测试和平台证据。交叉编译、无窗口 UI 测试及真实平台测试分别记录。

## 当前增量状态

当前能力以 `docs/feature-parity.md` 为准。文本规则、大文件合并、目录渐进扫描、目录合并、同步暂停续传、专用格式、夹具化远程来源、工作区恢复和 CLI 入口已有测试。跨进程 CAS、真实云账号、签名公证，以及 Windows 实时注册表、ACL、MTP、MSSCCI 仍未完成。
